# Streamline 0.3.0

- Cinematic featured titles and horizontal movie/series shelves.
- Recently added movies, based on dates supplied by your provider.
- Browse all with Newest, Title A–Z and Title Z–A sorting.
- Favourite channels and a recently played channel shelf.
- Existing movie progress, Continue Watching and account history are preserved by the database upgrade.
- Installable phone/Android TV testing APK, with direct downloads from GitHub Releases.

Download `streamline.apk` and install it on an Android 7+ phone or Android TV.

Permanent signing is deferred. This APK uses an Android testing key. Updating from a testing APK built on another runner may require uninstalling the older app, which clears its saved login/history.
