# Streamline 0.4.0

- Series Continue Watching with per-episode positions, resume choices, watched markers and an eight-second next-episode countdown. Cancel the countdown or play the next episode immediately, including across seasons.
- TV guide with a channel/time grid, device-local times, day selection, channel filtering, programme descriptions and remote focus navigation. Schedule availability depends on your provider. Unsupported full schedules fall back to clearly labelled limited EPG.
- My List for movies and series, saved separately for each account, with dashboard shelves and a saved-only filter.
- Playback recovery makes up to three automatic attempts, preserving on-demand position, with manual retry and cancellation. Pausing, backgrounding or leaving stops automatic recovery.
- Picture Fit, Fill and Stretch; select audio and subtitles supplied by the stream. Basic text and bitmap subtitle rendering is supported; elaborate subtitle positioning and styling are not reproduced.

Download **streamline.apk** to install on Android mobile or Android TV (Android 7.0+). This is a testing APK using the current disposable testing key; permanent signing remains deferred.

Global search is not included. Existing section searches remain available.

Automated tests cover storage upgrades, account separation, provider schedules, remote navigation, resume, episode transitions, track controls and recovery limits. Live provider playback and hardware remote/decoder checks still require a physical device.
