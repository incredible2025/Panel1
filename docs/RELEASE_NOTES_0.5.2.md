# ULTRAVPN PLAYER 0.5.2

Download **ultravpn-player.apk** for Android phones and Android TV (Android 7.0+).

## Your new identity

- ULTRAVPN PLAYER app name, supplied artwork and cyan/blue shield-play branding throughout the interface.
- New Android launcher icons, including adaptive and themed icon support.
- Matching launch/splash screens and a wide Android TV launcher banner.
- Updated player, licence-page and connection-report display names.
- Branded APK filename and GitHub release title.

The existing package ID and account/database identities are retained. Connection diagnosis, local recommendations, watch history, Continue Watching, My List, guide, Settings and both playback engines remain included.

This release publishes the branding update. The additional feature ideas discussed for a future release have not been added. The brand name does not introduce a VPN service or change DNS configuration.

Permanent signing remains deferred; this is a testing-key APK. Device-specific playback and remotes still need testing on the intended phone/TV.
