# Ultravpn-player 0.6.5

- App name updated to Ultravpn-player on Android phones and TV.
- Permanent download filename: Ultravpn-player.apk, retained for future releases.
- Existing accounts, settings, watch history and player features are retained when updating from the permanently signed 0.6.3 or 0.6.4 app.

Download Ultravpn-player.apk for a new installation, or use Settings > App updates in the installed app. Android installation approval is still required.
