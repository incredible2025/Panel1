# Ultravpn-player 0.7.2

Refines the television presentation while retaining the remote navigation and updater fixes from 0.7.1. The top navigation is quieter, category and channel lists use flat rows, and visible focus is concentrated on the active control. Selected categories use a slim accent marker rather than another outlined box.

Live TV has a larger preview, clearer channel typography and discreet channel numbers. The outer panel borders and repeated checkmarks have been removed. Movie posters have minimal framing so provider artwork carries the screen. Home and detail views use cleaner primary actions and less decoration. Artwork fallbacks use subdued gradients and initials instead of diagonal stripes.

Preview coverage includes the supplied-photo scenario: long UK categories, football channels, missing artwork and no programme guide, at 960×540 and 1280×720. Existing remote-only journeys, update actions, held-key scrolling, protection, playback and mobile regression checks remain required before compilation.

Version 0.7.2, Android build 19. Signing identity, stable `Ultravpn-player.apk` filename and embedded update endpoint are unchanged. Upload both APKs from the remote update ZIP before replacing update.json.
