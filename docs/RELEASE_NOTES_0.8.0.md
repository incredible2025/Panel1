# Ultravpn-player 0.8.0

Implements the approved Glass guide design for Android TV: a slim navigation bar, Inter typography, blue-to-teal background, compact category rail and a dense three-column guide. The guide shows real current, next and later programmes, loads schedules for visible rows only and retains stable remote focus while scrolling large catalogues. Missing EPG stays explicitly unavailable. Select a future programme for its description or open the live channel.

Home, Movies and Series use a shorter cinematic hero and six landscape cards across a standard TV screen. Continue watching, recently added titles, watch history, recommendations, category browsing, search, sorting and parental restrictions remain available. Browse all opens the compact category/grid view. The large-poster preference uses five cards. Account, diagnostic and update actions remain reachable using the remote.

The interface uses a 1024-wide design canvas scaled to the television viewport so its proportions remain consistent at 540p, 720p and 1080p. Programme information and artwork come from the signed-in provider; the approved concept's sample schedules and photographs are used only for visual tests.

Version 0.8.0, Android build 20. App identity, permanent signing certificate, stable Ultravpn-player.apk filename and remote update endpoint are retained. Upload both APKs from the remote-update ZIP before replacing update.json.
