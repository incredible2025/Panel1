# Ultravpn-player 0.8.2

TV login now opens a built-in remote keyboard. Choose a letter with the D-pad and press OK to type; select Done to continue to the next credential. This path does not depend on Android showing or operating its system keyboard.

The keyboard includes numbers, lower and uppercase letters, all printable ASCII symbols, space, delete, clear and password visibility. Back preserves draft input. A held OK cannot type unintended repeated characters. Physical keyboard character input and Unicode-aware backspace are supported. Use system keyboard remains an optional action for devices where native input works, with a return path to the built-in keyboard when native input closes.

The fixed TV login layout, visible App updates action and fixed Home canvas are preserved. Mobile login is unchanged.

Version 0.8.2, Android build 22. Permanent signing identity, app ID, embedded update feed and stable Ultravpn-player.apk filename are preserved. Upload both APKs from remote-update.zip before replacing update.json.
