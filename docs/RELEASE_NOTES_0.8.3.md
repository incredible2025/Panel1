# Ultravpn-player 0.8.3

TV Settings now uses a fixed Glass canvas with a section list, compact options and a separate explanation panel. Remote navigation moves within explicit zones. Long option lists show complete rows and a scrollbar; focusing a control no longer scrolls the whole page. Returning from dialogs and tools restores option focus.

Speed test shows Download, Upload, HTTP latency and Jitter together above fixed Start/Stop, Run again and Copy actions. Results, partial failures and longer explanations stay in a separate reading panel. Speed-test request failures now include the actual HTTP status and specific explanations for refusal, rate limiting, redirects, missing endpoints and service errors. Unmeasured values remain clearly labelled rather than shown as zero.

Connection diagnosis uses a check list beside the full evidence, causes and next steps. Run/Stop and Copy remain visible while reports are read. Updates uses the same fixed layout with accessible release notes and installation actions. Category management, favourite ordering and licences also use bounded TV panels. The Settings overview account card no longer scrolls.

Parental PIN creation, confirmation and unlocking use a masked built-in numeric TV keypad, with four-to-eight-digit validation. Mobile settings and forms retain their touch layouts. TV login, Home, app identity, permanent signing key and embedded update address are preserved.

Version 0.8.3, Android build 23. Upload both APKs from remote-update.zip before replacing update.json. Ultravpn-player.apk remains the stable Downloader filename.
